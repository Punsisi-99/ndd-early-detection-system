# Neurodevelopmental Disorder (NDD) Early Detection System

## Overview

The Neurodevelopmental Disorder (NDD) Early Detection System is a machine learning-powered web application developed to assist healthcare professionals in the early identification of neurodevelopmental disorders in children.

The system allows healthcare workers, particularly midwives and medical staff, to enter behavioral and developmental observations of children and receive a predictive assessment generated by a trained TabNet machine learning model.

The platform also provides administrative functionalities for managing prediction records and reviewing historical assessments.

## Project Objectives

* Support early detection of neurodevelopmental disorders.
* Provide a user-friendly interface for healthcare professionals.
* Utilize machine learning to improve screening efficiency.
* Store and manage prediction records securely.
* Generate explainable prediction results.

## Installation Guide

### 1. Clone Repository

```bash
git clone https://github.com/your-username/ndd-early-detection-system.git

cd ndd-early-detection-system
```

### 2. Backend Setup

Create virtual environment:

```bash
python -m venv venv
```

Activate environment:

Windows

```bash
venv\Scripts\activate
```

Linux / Mac

```bash
source venv/bin/activate
```

Install dependencies:

```bash
pip install -r requirements.txt
```

Run FastAPI server:

```bash
uvicorn main:app --reload
```

Backend runs on:

```text
http://127.0.0.1:8000
```

### 3. Frontend Setup

Install Node.js dependencies:

```bash
npm install
```

Run development server:

```bash
npm run dev
```

Frontend runs on:

```text
http://localhost:5173
```
